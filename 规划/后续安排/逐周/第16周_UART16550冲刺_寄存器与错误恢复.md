# 第16学习周：UART16550冲刺：寄存器与错误恢复

参考日期：2027-03-08～2027-03-14（北京时间）。核心段。实际执行前核对[假期日历](../02_日历与中国假期.md)；正式调休或公司加班与本周冲突时整周顺延，不在假期补课。状态：未开始。

## 工作问题与门槛

用一周限定冲刺，把UART从收发函数推进到初始化、FIFO、状态、错误和恢复。先用主机寄存器模型隔离ISA/启动难度，真实QEMU MMIO迁移留W25～26。

先修：上一学习周的必过项有源码、输入与调试证据；失败项未解决先重复上一周。 本周重要性：P0：确认16550模型而非16050；访问宽度/步长、DLAB、波特率分频、LSR、FIFO、轮询超时；i.MX UART另有寄存器。

## 精确选课与官方阅读

视频主看/补看：[O02 MIT6.S081 2021日程/2020录像](https://pdos.csail.mit.edu/6.S081/2021/schedule.html)LEC9 Interrupts的UART路径；[野火官方驱动视频](https://www.bilibili.com/video/BV1pf4y1974n/)检索“裸机 UART串口通讯”，对应裸机第12章，比较不同IP。

文字与源码：[TI TL16C550D官方手册](https://www.ti.com/lit/ds/symlink/tl16c550d.pdf)的DETAILED DESCRIPTION与寄存器定义；[QEMU serial.c官方实现](https://github.com/qemu/qemu/blob/master/hw/char/serial.c)核模型差异，不能把TI自动流控特性直接套QEMU；MIT的kernel/uart.c作阅读参照；[野火官方驱动教材分册目录](https://doc.embedfire.com/linux/imx6/driver/zh/latest/index.html)裸机第12章。

视频建议合计1～2小时，必要补看到3小时须挤掉选做，不挤编码。课程章节与手册章节分开，跨年MIT课程不要混编号。资料核验与播放/字幕限制见[课程表](../资料/01_C与系统课程章节核查.md)和[硬件架构表](../资料/02_外设架构QEMU与PCIe核查.md)。

## 每天做什么：正常周15小时

| 时间 | 具体动作与产物 |
|---|---|
| 周一 2h | 先写本周问题的预期图/表，再看指定视频、查手册。标出数据来源、控制/通知来源、对象或资源的归属。不能只抄笔记。 |
| 周二 2h | 复用W02寄存器模拟器，按TI手册扩展DLAB别名/LSR/FIFO最小模型，先明确每个状态位和读写副作用 |
| 周三 2h | 通过reg_read/reg_write接口写init/收发/timeout，测试输入和模拟时钟可控，不直接解引用假物理地址 |
| 周四 2h | 接入已有ring并统计溢出/错误，重复初始化和恢复，输出与i.MX原生UART差异表。 |
| 周五 2h | 开始故障注入：模拟TX不就绪、RX突发超过容量、parity状态和重复init；主机模型只证明程序对指定状态的处理，真实波形/硬件错误未验。 |
| 周六 5h | 2h定位/修复，2h正常与失败回归，1h闭卷解释和填写周报。没做完顺延，选做首先删减。 |
| 周日 | 休息，无看课和补债要求。 |

## 本周必过项

本周交付限定寄存器模型及驱动逻辑，有超时、统计和每位解释，不能称真实16550驱动已验收；W25～26再迁移QEMU验证MMIO/IRQ，不把启动代码学习偷偷塞入本周。

验收同时检查：功能正确、机制解释、独立实现、故障定位、他人可复现。可查手册，不能现场复制生成答案。至少一个30～60行或等价小任务由本人从空白完成，解释每个长度、指针、状态位和失败分支。
