# 维护方法

`生成周计划.py`保存W01～20和休息窗口，`深化周.py`保存W21～40。仅使用Python标准库，不安装依赖、不访问网络、不删除文件。

运行：`python "生成周计划.py"`。它会覆盖本目录上一级的逐周40份文件、02日历、03目录和日程核对JSON。**实际学习记录写实验仓库evidence，不写进生成文件，否则重建会覆盖。** 修改任务先改源数据，修改假期先改BREAKS；不需要重新检索课程或改变学习顺序。

运行前后检查：40周齐全、每周有三步实作、所有学习日期不与BREAKS重叠、本地Markdown链接可定位。生成器已内置数量/周一开始/不重叠/三步任务断言。正式调休或个人排班改变时人工补入窗口，不把本文件当实时节假日服务。

`日程核对.json`是生成结果，方便查日期；不是学习完成状态。`输入来源快照.json`和`交付文件清单.json`用于追溯本轮来源/输出，SHA256不代表学习效果或技术正确性认证。
