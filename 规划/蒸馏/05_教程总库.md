# 教程总库：按蒸馏主线选课

更新：2026-10-19。这是**唯一选课入口**，以[蒸馏结论](00_蒸馏索引与取舍.md)、[个人学习约束](02_面向本人工作的学习约束.md)和[工程判断框架](03_女娲方法蒸馏_工程判断框架.md)决定取舍。主线仍是 **C→外设→架构/QEMU→DMA/PCIe→系统协调**；备选课程可以换讲法，不能跳过独立实现、调试和验收。

日常只做三件事：从[逐周目录](../后续安排/03_逐周目录.md)打开本周任务；在这里选一位主讲；把视频里的机制用本周实验验证。一周通常只看相关1～2小时，不同时刷多套。替换讲师不增加周预算，不挤春节和其他休息窗口；日历见[假期安排](../后续安排/02_日历与中国假期.md)。

**保留关键纠偏：** EDU是传统PCI教学模型，只支持INTx/MSI，不能拿它验MSI-X或真实PCIe链路。默认28位DMA与Arm virt高地址RAM有冲突风险，第一轮用x86 guest；不能只把驱动mask改大。细节和进入门槛见[PCIe专项](../后续安排/07_PCIe专项路线.md)。QEMU通过不代替波形、实板时序、缓存一致性或物理链路验收。

## 如何选择、怎样避免重复学

1. **默认用首表**。同一个知识点主讲已能解释并完成实验，就跳过其他讲法；卡住时只换对应小节。
2. **视频、文档、实验各司其职**。视频建立图景；规范确认语义；源码/故障证据判断实现。指针/位域不能只看C++课，外设不能只看发送接收函数。
3. **中文优先的最短组合**：C03的C相关小节 + T03 + D01或D04 + O01；C标准、SoC手册、Linux/ISA文档仍保留。若希望纯C讲授，则C01/C02为主，中文课只补卡点。
4. **英文资料能用就用**。CS50有官网英文字幕/讲稿；其他视频的CC/中文机翻未逐集核，不承诺全部支持。Arm旧培训链接已经失去直接入口作用，优先免费官方指南。
5. **核查质量看证据**：优先机构/作者身份明确、章名可核、课件/源码/实验完整且解释版本与错误路径的课程。未逐集看完，不宣称“口碑第一”或用播放量/薪资标题背书。公开视频、免费文档、收费授课分别说明。

本轮补充依据：B站官方元数据接口（如[GDB课程](https://api.bilibili.com/x/web-interface/view?bvid=BV13U4y1p7kB)、[FFmpeg课程](https://api.bilibili.com/x/web-interface/view?bvid=BV1bT4y1w78z)）核作者/分P；作者仓库、机构课程表和官方规范核内容。元数据可读不等于视频已完整播放或内容全部正确；平台登录、清晰度和网络可用性由实际访问决定。旧课程的有用部分已经并入本页，旧多方向课表不恢复。

需要查核查细节时才打开：[C/系统章节依据](../后续安排/资料/01_C与系统课程章节核查.md)、[硬件/架构/PCIe依据](../后续安排/资料/02_外设架构QEMU与PCIe核查.md)、[实验环境入口](../后续安排/资料/03_实验环境入口与视频备选.md)。平时留在本页选课，然后回本周任务。
