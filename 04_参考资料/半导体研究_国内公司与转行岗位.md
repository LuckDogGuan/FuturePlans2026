## 1. 这次按你的真实目标筛选

- 主项是**半导体公司的 Linux / C / C++ 软件研发**，关注 SoC、CPU、GPU、NPU 的软件底座；GUI 是辅助工具和交付能力的加分项。
- 不把普通后台开发、模型训练、AI 应用、音视频算法作为推荐主线。芯片 Runtime 也需看实际任务：设备内存/调度/同步，和图优化/算子/模型精度，是不同专项。
- 你已有约 4 年仪器软件经历、近期 Linux 二次开发、少量 STM32 调试、野火 i.MX6ULL Pro 开发板，愿意补硬件基础。这些能帮助开始实验，**尚不能等同于 2～3 年 Linux 驱动、BSP、OpenBMC 或芯片 Runtime 工作经验**。
- 你即将取得的本科是**产品设计专业自考本科**。下面写明“计算机/电子相关专业”的岗位均存在筛选风险；未写全日制、未写专业或未写学历，均不自动等于接受你的学历背景。应如实争取招聘方是否允许以实际开发经历替代专业要求。
- 工时先筛：拒绝长期大小周、常态 21 点、夜间待命、持续高压及反复救火。愿补硬件知识不等于接受上述工作安排。

## 3. 工作到底是什么，差距在哪里

### A. 晶晨通用驱动 J11734：从一种外设子系统深入

官方职责涉及通用外设模块维护、新功能、问题分析和文档，并与芯片设计、硬件、FAE 协作。招聘要求熟悉 Linux 字符设备以及用户态和内核态交互。[官方 JD](https://amlogicsh.zhiye.com/social/detail?jobAdId=7a09ec22-6528-47b8-8c0a-1dc5153b3c8d)

**对你的意义（推断）**：你的仪器通信和完整交付经验可以帮助理解接口需求、复现问题和验收；真正要新增的主项是 Linux 驱动资源管理、设备树、设备模型、总线及硬件问题定位。不能仅把已有 Qt 代码搬上板子当成驱动能力。

同公司更深的目标是 **Linux 内核驱动开发工程师（Upstream 社区方向）J11742**：上海，社招，2026-09-24，外设驱动、DeviceTree/dt-binding、补丁 review 及合入，要求理解调度、内存、中断等；该详情未写学历专业或年数。这是积累真实驱动与上游经验后的目标，不是推荐你同时学完所有内核模块。[J11742](https://amlogicsh.zhiye.com/social/detail?jobAdId=e704a18a-479d-4dbf-8a44-c4992cc2c8fa)

### B. 乐鑫 Linux：SoC适配、驱动、开源软件生态

岗位覆盖 Linux 平台 bring-up、Linux/U-Boot 驱动、系统问题定位、社区提交；要求 Buildroot/Yocto 等裁剪移植经验、真实硬件、C/Python、英语，并明确要求有效使用 Coding Agent。多媒体驱动只是加分项。[官方 JD](https://www.espressif.com/zh-hans/job-detail/10575)

## 5. 怎样从这些岗位做长期选择

以下是依据职责与现有经历的判断，不是行业工资统计或录用概率。

1. **第一候选：Linux驱动工程师 / SoC BSP软件工程师。** 更能直接利用现有板子补主项：交叉构建、启动、设备树、外设、资源/中断、问题定位。可延伸为外设子系统负责人、Linux内核工程师、平台稳定性/功耗性能工程师，也可以长期留在SoC软件，不必都转GPU。
2. **第二候选：OpenBMC软件工程师 / BMC固件工程师。** 明确贴近CPU和服务器生态的软件底座。要实际喜欢服务器管理、固件和跨硬件定位；与Linux驱动共用部分基础，但有IPMI/Redfish/MCTP/主机适配等专项。
3. **远期候选：GPU/NPU用户态驱动工程师 / 设备Runtime研发工程师。** 更直接服务算力，进入门槛和平台专项更大。优先设备内存、队列、异步与同步、设备提交及profiling；不要把模型训练或普通AI应用塞进这条路线。
4. **有条件候选：芯片软件验证开发工程师 / 系统性能工具开发工程师。** 必须看是否能编写自动化工具、复现与定位内核/驱动缺陷、性能测量并参与研发闭环。重复点击测试、固定脚本执行、生产线上测试岗位，与长期研发主项不同。赛昉当前系统测试JD要求五年以上服务器专项，不能当成容易入口。

**最关键的门槛**：这批多数具体JD要求CS/EE相关专业，部分要求明确专项年限。你的产品设计自考本科不能被写成自动满足；也不能凭学历形式就断言永远进不了。下一步应针对具体公司和团队，核实“4年实际软件经历是否允许替代专业限制”，并以本人能解释、修改、定位的Linux项目争取。界面能力可用于调试可视化、工具和交付，仍只作为加分。

## 6. 收入与工时必须分别核实

- 本轮上述官方JD未公开工资，不能保证其中任一能给税前15K以上。即使其他招聘平台广告出现高薪，也要区分对应职位、城市、年限、专业、自考接受度、基本工资与条件奖金。
- 社招JD中的“客户支持”“压力”“bring-up”“芯片设计协作”是需核实工作安排的线索，不能直接换算成996、955或加班概率。公司福利及弹性办公宣传也不能证明团队真实工时。
- 对你重要的是**具体团队**最近一个月通常下班时间、周末加班频率、新芯片阶段繁忙持续多久、有无夜间故障响应、是否驻场以及补偿方式。未有证据前标“工时未知”，不把外企/国产/半导体标签当结论。
