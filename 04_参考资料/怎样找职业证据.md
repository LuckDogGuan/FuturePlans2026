# 怎样找职业证据

更新：2026-10-19。围绕已确定的芯片软件主线查实际岗位，不重新开启四方向筛选。

## 分清证据类型

| 类型 | 能支持什么 | 不能支持什么 |
|---|---|---|
| 用户自述 | 偏好、经历、收入目标和生活边界 | 专项能力已经验收 |
| 源码/版本/对话抽查 | 项目做了什么、本人提出过哪些判断 | 每行本人独立实现、现在已会全部技术 |
| 小项目与复盘 | 一项任务的完成情况、卡点和兴趣 | 长期适合度、市场工资 |
| 官方具体岗位 | 职责、门槛、地区及页面明示条件 | 全市场代表性、955或本人可获报价 |
| 面试/录用 | 对当前个人与岗位更直接的反馈 | 未来几年一定稳定或涨薪 |
| 行业研究/预测 | 变化线索和研究样本内的现象 | 厦门细分岗位数量、个人成功率 |

来源日期、原文链接、未知项和适用限制一起记录。

## 岗位采样方法

从[现行路线](../规划/后续安排/01_总路线与能力优先级.md)的BSP/驱动、平台软件、芯片诊断职责采3～5个具体职位。数量用于控制工作量，不是统计显著性保证。
城市和资历尽量相近；直招、外包、售后支持分开；同公司同岗位去重。记录主责、必需技能、学历、薪资口径、值班和现场分工，见 [岗位与投递记录](../03_学习路线/岗位与投递记录.md)。
旧芯片公司研究只作为带日期的职责线索，当前招聘状态、学历接受和团队条件要重新核查；官网技术教程不能填补招聘证据。

先按 Qt 主责、健康、正常收入底线和职责筛选，再比较积累与兴趣。没有回复记原因未知，不自行归因学历。
所有方向都按实际模块责任判断深度；职位名称、底层标签和“AI”名称不替代工作内容。

## 足以推进决定的证据

阶段门槛中的独立实现/排错证据；能如实讲述的具体案例；可接受城市中的岗位与缺口；收入/工时/职责的进一步沟通。
仍有关键条件未知，就继续在职核对，不把文件完成当成转型完成。
