## 8. 2026-10-05 补充：半导体行业优先级与岗位研究口径

这是本轮新增的核心要求，优先级高于旧的“泛软件四方向”框架。

- **行业优先：半导体/芯片及其基础工具链。** 目标不是因为 AI 热而转 AI 应用，而是进入 GPU、CPU、NPU、SoC、EDA 等“算力与芯片基础设施/铲子行业”。AI 可以是芯片的客户、负载或应用场景，但职业主项应是芯片底层/系统软件本身。
- **大企业优先，中小企业补充。** 国内重点长期观察：紫光展锐、摩尔线程、沐曦、寒武纪、昆仑芯、海光、飞腾、兆芯、龙芯、晶晨、瑞芯微、全志、乐鑫、黑芝麻智能、地平线、平头哥、景嘉微、赛昉等；国外/国际重点：NVIDIA、AMD、Intel、Arm、NXP、MediaTek，以及 EDA 的 Synopsys/Cadence/Siemens EDA 等。
- **Qt/界面开发只算加分项，不再作为主路线。** 可以用于调试工具、诊断工具、性能可视化、内部工程工具，但核心竞争力必须逐步变成 Linux/C/C++、系统软件、驱动/固件、芯片调试与问题定位。
- **不把后台开发、AI 应用开发、普通模型调用、图像/视频算法作为默认主路线。** 若岗位名称含 AI，也必须检查实际职责；只有其核心工作是设备驱动、Runtime、固件、系统性能、编译/工具链等底座工作时才纳入候选。
- **硬件知识可以补。** 允许补数字电路、计算机组成、SoC/总线、中断/DMA/PCIe、看原理图和 datasheet 等必要知识；但不默认接受长期板级救火、频繁现场支持或常态夜间响应。

### 8.1 当前优先研究的岗位族

1. **SoC Linux BSP / Linux 驱动 / Kernel Engineer**：最适合作为第一层转型目标，重点是 Device Tree、U-Boot、外设驱动、内核设备模型、中断/DMA、系统启动与故障定位。
2. **芯片固件 / Platform Firmware / BMC / Boot / RTOS**：包括 BIOS/UEFI、OpenBMC、SoC 固件、GPU/加速器固件；与 Linux 系统软件相邻，但需要更多硬件与启动链知识。
3. **芯片诊断软件 / Silicon Validation Software / 开发工具**：开发测试 API、trace、诊断程序、硅后问题复现和根因定位工具。此类岗位比纯 IC 设计更能承接已有 C++ 工程经验，值得重点研究。
4. **GPU/NPU 用户态驱动 / Runtime / 系统软件 / 性能工具**：长期目标之一，重点是内存、队列、同步、异步 DMA、任务提交、profiling、driver/runtime 交互，而不是模型训练。
5. **CPU/GPU 系统性能与平台软件**：Linux kernel、虚拟化、调度/内存、性能分析、平台 enablement；通常门槛更高，可作为中长期深化方向。
6. **EDA 软件研发**：Synopsys/Cadence/Siemens EDA 等公司的 C/C++/Linux 软件研发、仿真/验证工具、性能工具。它同样属于半导体“铲子行业”，可减少对消费应用层业务的依赖，应纳入候选对比。

### 8.2 当前市场核查后的初步判断

- **15K+ 并不是半导体系统软件方向最难的门槛。** 已看到紫光展锐 Linux Kernel 约 30–45K·15薪、Android/Linux 驱动约 15–25K；黑芝麻智能 Linux 驱动约 20–40/50K·15薪；地平线芯片系统 BSP 约 20–40K·15薪；摩尔线程 GPU 内核驱动公开聚合样本约 30–50K。第三方标价只作市场样本，不等于本人可拿到的 offer。
- **真正风险是学历专业与专项经验。** 很多核心岗位写 CS/EE/CE/电子/通信相关本科或硕士，并要求 2～5 年 Linux 驱动、BSP、固件或 GPU 软件经验。产品设计自考本科不能自动算“相关专业”，需要用真实软件年限、Linux 项目、可解释的驱动/系统软件作品争取 HR 和技术面接受。
- **当前最现实的转行入口仍然偏 SoC Linux BSP/驱动、嵌入式 Linux 平台软件、芯片验证/诊断工具。** 直接跳到 NVIDIA/AMD 的高级 kernel/GPU driver、GPU runtime 核心岗位通常专项门槛过高，应把它们作为长期岗位标杆而不是下一份工作的唯一目标。
- **工作强度不能按“半导体”“外企”“国产 GPU”统一判断。** bring-up、流片后硅调试、量产、客户问题和版本发布阶段容易出现高峰；客户支持/现场调试/跨时区协作是需要重点问的问题。筛选时继续坚持：不接受长期大小周、常态 21 点、夜间待命和频繁硬件救火。
- **大厂岗位地图和本轮具体证据另存：** [半导体大厂岗位地图_2026-10-05补充](../04_参考资料/半导体大厂岗位地图_2026-10-05补充.md)。后续方向比较、体验项目和学习路线都应以这份半导体岗位族为主，不再默认沿用“后台/音视频/泛设备应用”的旧框架。
